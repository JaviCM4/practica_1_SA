# Session-Based vs JWT Authentication

Proof of Concept (POC) que compara dos mecanismos de autenticación: **Session-Based Authentication** y **JSON Web Token (JWT)**.

El objetivo de la prácticas es demostrar las diferencias entre ambos enfoques, analizando su funcionamiento, ventajas, desventajas y casos de uso mediante dos implementaciones independientes desarrolladas con **Express.js** y **Vue.js**.

---

## Tecnologías

### Backend

- Express.js
- Node.js
- PostgreSQL (o MySQL)
- Redis (para Session-Based)
- express-session
- jsonwebtoken
- bcrypt
- dotenv

### Frontend

- Vue 3
- Vue Router
- Pinia
- Axios
- Vite
